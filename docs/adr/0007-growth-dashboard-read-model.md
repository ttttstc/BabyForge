# 成长页使用派生只读模型，记录页作为唯一事实写入口

现有阶段页允许直接勾选里程碑，但新的成长页同时聚合测量、阶段知识、计划项和发展观察；如果继续在多个页面写入，会形成重复表单、含混状态和无法追溯的第二数据源。成长页因此只从宝宝档案、有效 `CareEvent`、`CarePlanItem`、确定性国家标准评估和版本化成长知识包派生页面模型；所有宝宝事实的新增、纠正和作废统一进入记录页。成长页可以保存筛选、折叠和浏览位置等界面状态，并通过带返回地址的深链发起预选记录流程，但不直接写入事实账本。

## Consequences

- 大盘、曲线、阶段详情和成长记录使用同一组事实与评估结果，不持久化第二份 `GrowthState`。
- 父母行动完成、发展观察和活动尝试会比页内一键勾选多一次记录跳转，但能复用统一校验、失败重试、纠正、作废和并发协议。
- 现有 `milestoneRecords` 必须按语义迁移，任务型记录不能自动解释为宝宝发展能力。
