# ADR-0005：记录工作台只负责事实，今天页只负责查看

BabyForge 将“记录”作为创建、核对和管理事实的唯一工作台：默认突出喂养、睡眠、尿布、用药、体温和成长六类高频事实，并以次级入口保留症状观察和专业结论等其他事实。宝宝档案、照护计划、关注事项和咨询问题移出记录工作台；“今天”页只展示由已保存事实确定性计算出的汇总并提供带类型的跳转入口，不再直接保存记录。这样既建立稳定的“今天用于查看、记录用于操作”心智模型，也避免既有低频事实能力回退。

## 被否决的方案

- 不把记录入口分散在 Today、Stage 和 Records 三处：分散入口会让照护者难以找到正确位置，也会让 Today 的快捷入口被当成低质量事实的绕过路径。
- 不在 Today 页继续保留一步保存按钮：Today 只查看的心智模型更稳定，所有新事实都经过 Record Center 的 P0 载荷校验和同一套可追溯生命周期。
