# ADR-0005：确定性决策内核与 AI 解释层分离

- 状态：已采纳
- 日期：2026-08-07

## 背景

奶爸AI需要理解自由表达并生成易懂回答，但健康相关行动必须可复现、可审核，并且不能随模型或措辞变化。完全由规则生成自然语言会造成交互僵硬，完全由模型决定行动又无法保证一致性和最低安全边界。

## 决策

宝宝上下文由正式档案、`CareEvent` 和 `BabyStateSnapshot` 确定性构建；版本化且已审核的 `DecisionUnit` 产生 `DecisionResult`，负责适用范围、必要事实、信息充分性、最低行动要求、复查和升级条件。信息充分性门未通过时，只返回缺失事实和下一条关键问询，不形成个体化结论；已经确认的危险信号先触发最低行动要求，不等待其余问询完成。奶爸AI只负责意图理解、待确认事实草稿、审核知识检索和结果解释，不能创建、修改或降低最低行动要求。所有正式写入均需用户确认并通过工具校验。

## 后果

- 相同事实和规则版本得到相同决策结果，可进行边界测试和历史复现。
- 缺失、冲突和不确定事实不会被模型补全，问询过程可追溯并允许用户回答“不确定”。
- 模型更换不会改变最低行动要求。
- AI 输出必须引用决策结果和审核知识；不一致时由输出或工具 Guardrail 阻断。
- 新场景必须先具备审核通过的决策单元，AI 才能提供对应的个体化健康行动。
