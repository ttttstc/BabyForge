# ADR-0001：家庭共享账号与记录人分离

- 状态：已采纳
- 日期：2026-08-06

## 背景

月嫂和家长需要共同查看同一个宝宝的记录，但产品不需要为每位照护者建立独立登录账号或权限体系。与此同时，时间线需要回答“这条记录由谁录入”，而不是推断“谁执行了照护”。

## 决策

家庭账号作为唯一的访问边界；账号内维护可共享的记录人名单。每台设备只在本地保存当前选中的记录人，提交事件时写入记录人的 id 和显示名快照。记录人不是授权角色，也不代表实际执行者。

## 后果

- 多台设备看到同一份记录人名单，切换记录人不需要重新登录。
- 记录人名单的增删改需要云端同步。
- 以后若要增加成员权限，应另行设计账号成员模型，不把记录人字段复用为权限字段。
