# ADR-0002：事件、计划与关注事项的边界

- 状态：已采纳
- 日期：2026-08-06

## 背景

现有页面把已经发生的照护事实、未来待办、长期关注主题混在不同的历史数组中。继续扩展会造成“完成待办”和“发生了一次照护”无法互相追溯，也会让规则误把计划状态当成健康事实。

## 决策

- `CareEvent` 只表示已经发生或被观察到的事实。
- `CarePlanItem` 只表示未来或预期事项；完成计划时同时产生对应的 `CareEvent`。
- `Concern` 表示一段需要持续关注的主题，可关联多条事件，但不等于诊断。
- 支持流程只生成照护者下一步提示（`caregiverGuidance`），用于整理观察和联系专业人员；它不是健康评分、诊断或就医分级，医生摘要不展示该内部模式。
- 旧版任务、观察和成长记录迁移为上述模型的只读兼容桥；新写入统一先生成 `CareEvent`，现有页面暂时继续读取旧字段。

## 后果

时间线、趋势和行动指导可以从同一事件源构建；计划的完成状态不会伪装成宝宝已经发生的健康事实。兼容桥会在 PR1 期间保留，待后续页面迁移完成后再移除旧数组。
