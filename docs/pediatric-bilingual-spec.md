# BabyForge 常见儿科病与双语扩展 Spec

## 目标

`#/topic/pediatric-diseases` 提供疾病速查和器官学习两个入口。两个入口共享同一套 `DiseaseTopic`、来源审核、解剖绑定与详情，不建设病例弹窗或第二套疾病内容。

## 内容边界

- Registry 覆盖 Issue #14 列出的 51 个 0–6 岁家庭高频疾病主题。
- 每个主题包含定义、位置、病因、传播（适用时）、机制、影响、症状、病程、观察、一般处理、家庭护理、不建议行为、就医科室、就医准备、预防、来源、版本与审核状态。
- 科普不提供诊断、健康评分、个体化处方、剂量或独立危险信号阈值。判断宝宝当前状态时进入 #12 的 `DecisionUnit`。

## 双视角

疾病视角首屏提供正式名、别名和俗称搜索、分类筛选及当前年龄推荐。选择疾病后定位到 3D 展示区，再展示完整指导。

器官视角展示 9 个现有 3D 器官资源及耳、鼻、咽喉、口腔、胃食管、下尿路和骨骼等计划资源。点击关联疾病后切回疾病视角并进入同一 `DiseaseTopic` 选中态。

## 3D 与缺省态

一个疾病可拥有多个纵向 `displayUnits`。只有存在准确 `AnatomyAnchor` 的模型才标记为 `AVAILABLE`；不以整个器官替代已有的亚器官、黏膜、表面或通路。模型不存在、WebGL 不可用或运行时加载失败时显示统一缺省态，疾病内容和就医入口继续可用。

## 双语与来源

默认 `zh-CN`，设置页可切换 `en-US`。疾病字段、器官字段、缺省态、来源标签和交互文案均提供双语。每个主题至少绑定一项 WHO、CDC、AAP 或 NHS 的可追溯权威来源，内容版本为 `disease-registry-2026-08-08`。

## 验收

- 毛细支气管炎精确描述末端细支气管；没有细支气管模型时使用缺省态。
- 手足口病按口腔黏膜、手掌和足底展示三个单元。
- 新生儿黄疸区分皮肤/巩膜表现层与胆红素处理通路。
- 呼吸系统器官页始终显示相关疾病，点击肺炎进入疾病选中态。
- 急性中耳炎定位鼓膜后中耳腔，不笼统标注为“耳朵”。
- 所有高频主题在无模型时仍能查看完整指导、来源和 #12 健康预评估入口。
