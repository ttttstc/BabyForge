# 子议题 6：非成员临时访客链接

## 唯一目标

允许家庭向非成员分享短效只读链接，展示经过脱敏的宝宝信息，不创建 Household membership。

## 设计

- Owner 创建高熵随机 Token，数据库只保存 hash；默认有效期短（设计实现时固定为 2 小时），可主动撤销。
- 访客视图使用独立查询和响应模型，默认隐藏照片、原图 URL、姓名、精确出生日期、健康事件细节、AI 对话和其他敏感字段。
- 访客只读，不可写入、上传、下载原图、调用 AI 或枚举家庭资源。
- Token 一旦撤销、过期或家庭删除，立即拒绝。
- 访问审计记录时间、资源范围和结果，不记录 Token 明文。

## 非目标

将访客伪装成 Guest 成员、复用正式登录 Session、展示照片、复杂分享权限编辑。
