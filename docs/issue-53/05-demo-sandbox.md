# 子议题 5：隔离演示沙盒

## 唯一目标

提供中性 Mock 与品牌只读展示两个产品能力演示身份，但不让演示身份进入正式用户或生产家庭授权体系。

## 设计

- 演示账号和密码只保存在服务端运行时 Secret 中，验证成功后使用每个浏览器独立的虚拟数据沙盒。
- 中性 Mock 使用虚构宝宝；品牌展示通过独立短期 Session 读取配置宝宝的脱敏资料与真实照片。
- 不创建正式 User、Household membership 或持久化家庭数据。
- 登录页明确标注“演示模式”；退出或刷新可重置沙盒。
- 中性 Mock 不含特定家庭身份；经资料所有者确认，品牌展示放行配置宝宝的昵称、真实出生日期、基础档案、成长记录、喂养/睡眠/尿布记录和照片。
- 家庭成员姓名、邮箱、问题、观察、用药、疾病、体温、AI 对话与配置不进入展示 API。

## 实现边界

- 浏览器构建、仓库、文档和 D1 均不包含演示凭据；公网部署通过 `BABYFORGE_PRESET_ACCOUNTS` Secret 开启入口。
- 中性 Mock 从 `createDemoWorkspace()` 创建虚构数据；品牌展示从专用只读 API 读取 allowlist 字段。
- 体验内容和奶爸 AI 使用浏览器内预置结果；正式同步、设置和账号接口均不参与演示流程。
- 品牌照片仅通过专用内容接口查看，不提供原文件名或下载响应；两个演示身份的所有写入口均禁用。
- 迁移 `0016_disable_public_demo_accounts.sql` 停用旧的共享 Guest 演示账号及会话，避免它们继续进入正式家庭授权链路。

## 非目标

共享 D1 演示家庭、真实邮件、跨浏览器写入或任何正式家庭成员权限。

## 验收

固定凭据可进入演示；刷新后恢复虚构初始数据；演示浏览、体验内容和 AI 不发出 `/api/*` 请求；演示操作不影响正式账号和生产数据；构建产物不包含生产 Secret。
