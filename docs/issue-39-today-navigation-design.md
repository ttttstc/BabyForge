# Issue #39：Today 与全局导航收敛

## 目标

保持桌面端三栏工作台和现有视觉体系，收敛 Today 的阅读顺序，并将一级业务导航固定为“今天 / 记录 / 成长 / 健康 / 经验”。奶爸 AI 保留为所有已登录页面可达的全局能力，不作为第六个业务标签。

## 已确认设计

- 桌面 Today：左栏从当前宝宝基础信息开始，其后显示喂养、睡眠、尿布、用药四项汇总；中栏保留 BabyAlbum；右栏只显示每日事项。
- 移动 Today：当前宝宝、四项汇总、BabyAlbum、每日事项。
- Today 不展示当前阶段待办或最近保存事实；已保存事实仍在记录中心查看。
- 四项汇总卡主体进入当天对应事实筛选；`＋` 直接打开对应记录表单；保存或取消返回 Today。
- 健康区使用“疫苗计划 / 常见儿科病 / 器官教学”三个并列标签，默认打开疫苗计划；旧深链继续兼容。
- 全局 AI 入口覆盖所有已登录页面，打开时携带 `returnTo`，关闭后回到原页面；登录和建档页不展示。
- 移动端继续使用 Header 第二行五标签导航，不新增底部导航。
- 所有新增及受影响按钮必须保持图标和文字视觉居中；视觉验收覆盖桌面与移动端。

## 非目标

不重构 Record、Growth、BabyAlbum、疫苗详情、常见儿科病内容、器官 3D 工具或奶爸 AI 核心能力，不改变桌面三栏宽度逻辑。

## 视觉停止点

核心交互完成后先生成 1440px 桌面 Today、390px 移动 Today 和健康区截图。视觉确认后再完成全量测试与收尾。
